📊 Architectural Comparison
❌ Vulnerable / Traditional Storage

Plaintext token saved directly to localStorage or sessionStorage. Vulnerable to XSS key theft, accidental browser extension leakage, and log scraping.

✅ This Architecture (AES-256-GCM + RAM)

Ciphertext saved to IndexedDB. Non-exportable device key locks cipher bundle. Plaintext lives only in memory variables during active API transmission and is purged immediately.
